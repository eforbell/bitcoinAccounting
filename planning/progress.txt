## Codebase Patterns

- **Named Placeholders**: Both sqlite3 and psycopg2 support `:named` syntax with dict parameters. Use this for cross-database compatibility instead of `%s` or `?`.
- **Python 3.9 Type Hints**: Add `from __future__ import annotations` to use `|` union syntax on Python 3.9.
- **Optional Dependencies with mypy**: Use `TYPE_CHECKING` pattern to conditionally import types without runtime failures.
- **SQLite Row Factory**: Set `connection.row_factory = sqlite3.Row` to enable `dict(row)` conversion.
